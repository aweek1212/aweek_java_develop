# aweek_java_develop_claude

김영한님의 인프런 자바 강의를 들으며 **배운 개념을 쇼핑몰 백엔드 프로젝트에 바로 적용해 보는** 학습 저장소입니다.
순수 자바 콘솔 프로그램에서 시작해, 강의 진도에 맞춰 리팩토링하면서 최종적으로 스프링 부트 REST API까지 키워 갑니다.

- 전체 계획: [docs/ROADMAP.md](docs/ROADMAP.md)
- 미션 문서: [docs/missions/](docs/missions/)

## 진행 방식

1. 강의 섹션을 듣는다.
2. 그 진도에 맞는 미션 문서를 읽고 **직접 구현**한다. 막히면 Claude에게 힌트를 요청한다.
3. 미션 문서의 확인 코드로 결과를 맞춰 본다.
4. Claude에게 "미션 N 리뷰해줘"라고 요청하고, 리뷰를 반영한다.
5. 미션 단위로 커밋한다.
6. 다음 진도를 들으면 "OO까지 들었어"라고 알려 주고 다음 미션을 받는다.

## 실행 방법

빌드 도구 없이 순수 자바로 진행합니다. (스프링 부트 단계에서 Gradle로 전환)

**IntelliJ**
1. `File > Open`으로 이 폴더를 연다.
2. `src` 폴더 우클릭 → `Mark Directory as > Sources Root`
3. `src/shop/ShopMain.java`를 실행해 "쇼핑몰 프로젝트 시작!"이 나오면 준비 완료.

**터미널** (Java 22 이상, 저장소 루트에서)

```bash
java src/shop/ShopMain.java
```
